# Satellite Data Suitability Assessment Pack

Free supporting resources | SSE-DS-001 | Published by MGCA Ltd

Choose satellite imagery around the monitoring task.

## Start with the product you purchased

Unzip your purchased pack and open START_HERE.pdf or START_HERE.docx. This public folder supplements the pack with free guidance and small format-checking examples. It does not contain the paid workbook, detailed guide, assessment materials, product automation or release ZIP.

## First checks

1. Check temporal coverage and usable observations as well as nominal resolution.
2. Retain access terms, quality flags and processing assumptions with a dataset comparison.
3. Use representative samples before deciding that a dataset meets an observation requirement.

## Try the free example

From the root of this resources repository, with Python 3.10 or later:

```text
python tools/inspect_file.py products/zm1tj-satellite-data-suitability-assessment-pack/support-example.csv --required item --required status
python tools/inspect_file.py products/zm1tj-satellite-data-suitability-assessment-pack/support-example.json
```

The helper reports file structure only. It does not score readiness, decide acceptance, compare architecture options or replace the purchased product.
