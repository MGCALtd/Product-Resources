# Quantum Use-case Assessment Pack

Free supporting resources | QCE-UA-001 | Published by MGCA Ltd

Define a fair quantum-versus-classical comparison.

## Start with the product you purchased

Unzip your purchased pack and open START_HERE.pdf or START_HERE.docx. This public folder supplements the pack with free guidance and small format-checking examples. It does not contain the paid workbook, detailed guide, assessment materials, product automation or release ZIP.

## First checks

1. Define the task and a fair classical comparison before discussing a quantum approach.
2. Retain dataset, resource and measurement assumptions for each proposed experiment.
3. A possible use case is a research question, not a demonstrated advantage.
