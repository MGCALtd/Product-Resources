# Architecture Diagram Review Pack

Free supporting resources | SAC-DR-001 | Published by MGCA Ltd

Make architecture diagrams easier to understand and review.

## Start with the product you purchased

Unzip your purchased pack and open START_HERE.pdf or START_HERE.docx. This public folder supplements the pack with free guidance and small format-checking examples. It does not contain the paid workbook, detailed guide, assessment materials, product automation or release ZIP.

## First checks

1. State the intended audience and the decision the diagram must support.
2. Check system boundaries, relationships and the meaning of the notation.
3. Keep a drawing clarity finding separate from a claim about the running system.

## Try the free example

From the root of this resources repository, with Python 3.10 or later:

```text
python tools/inspect_file.py products/belbi-architecture-diagram-review-pack/support-example.csv --required item --required status
python tools/inspect_file.py products/belbi-architecture-diagram-review-pack/support-example.json
```

The helper reports file structure only. It does not score readiness, decide acceptance, compare architecture options or replace the purchased product.
