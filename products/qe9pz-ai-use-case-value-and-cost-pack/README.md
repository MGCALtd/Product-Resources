# MLCLabs AI Use-case Value and Cost Pack

Free supporting resources | MLC-VC-001 | Published by MGCA Ltd

Check the economics of an AI workflow before scaling it.

## Start with the product you purchased

Unzip your purchased pack and open START_HERE.pdf or START_HERE.docx. This public folder supplements the pack with free guidance and small format-checking examples. It does not contain the paid workbook, detailed guide, assessment materials, product automation or release ZIP.

## First checks

1. State volume, time period, currency and units before calculating an estimate.
2. Do not assume time saved automatically becomes cash saved.
3. Keep measured inputs separate from assumptions that still need a pilot.
